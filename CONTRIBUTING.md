# Contributing to AgriWater AI

Thank you for your interest in contributing to AgriWater AI.

The project aims to build an open, extensible platform for smart irrigation and data-driven water management. Contributions from developers, students, researchers, and agriculture or IoT enthusiasts are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch:

```bash
git checkout -b feat/your-feature-name
```

3. Make focused changes.
4. Test your changes locally.
5. Follow the existing project structure and coding conventions.
6. Write clear commit messages.
7. Open a Pull Request describing:

   * What changed
   * Why the change is useful
   * How the change was tested

## Development Principles

* Keep changes small and focused.
* Do not commit passwords, API keys, `.env` files, or other secrets.
* Use environment variables for configuration.
* Prefer readable and maintainable code over unnecessary complexity.
* Add tests when introducing important behavior.
* Update documentation when changing setup, APIs, or architecture.
* Discuss large architectural changes in an issue before implementing them.

## Commit Message Examples

```text
feat: add irrigation risk calculation

fix: handle duplicate field names

docs: improve local setup instructions

test: add field API tests

refactor: separate field business logic
```

## Code of Conduct

Be respectful, constructive, and welcoming. We want AgriWater AI to be a collaborative learning environment for contributors with different backgrounds and experience levels.
